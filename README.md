# 光标运动模糊 - 增强版 (Cursor Motion Blur Enhanced)

[Windhawk](https://windhawk.net/) mod，为鼠标指针添加高速运动模糊拖尾，Direct2D 硬件加速渲染。

## 原作者声明

本项目基于 [TheatriChris](https://github.com/chrisc44890) 的 **Cursor Motion Blur** mod 二改汉化与功能增强，遵循 MIT 许可证。

原始代码的核心渲染逻辑（Direct2D 多边形网格、Chaikin 细分、游戏检测、分层窗口覆盖）归原作者所有。

## 功能特性

- **延迟渲染**：拖尾头部缓动跟随光标，滞后平滑（0-10 可调）
- **粒子消散**：拖尾淡出时释放迷你小球，模拟消散渲染（可开关、密度可调）
- **点击星爆**：点击时从光标位置径向迸发粒子（可开关、数量可调）
- **平滑渐变**：拖尾从头到尾透明度渐变淡出（可开关）
- **微发光效果**：拖尾外圈柔和发光，强度可调（0-100）
- **三种形状**：锥形 / 圆点链 / 等宽带
- **11 种颜色模式**：
  - 经典黑白
  - 单色（自定义颜色）
  - 多色渐变（自定义头尾色）
  - 彩虹流动
  - 暖色调流动
  - 冷色调流动
  - 霓虹脉冲（亮度呼吸）
  - 速度变色（慢蓝快红）
  - 流动条纹（双色交替流动）
  - 火焰（黄橙红渐变+闪烁）
  - 极光（绿青紫流动）
- **点击波纹**：按下鼠标左右键时产生扩散波纹（可开关）
- **游戏检测**：全屏 DirectX 游戏时自动禁用
- **零输入延迟**：直接基于硬件光标坐标绘制
- **动态渲染**：鼠标静止且无特效时 CPU 占用为 0%

## 安装

1. 安装 [Windhawk](https://windhawk.net/)
2. 打开 Windhawk，点击「创建 Mod」
3. 将 `cursor-motion-blur-cn.cpp` 的全部内容粘贴到编辑器中
4. 保存并启用

## 颜色格式

自定义颜色使用十六进制 RGB，例如：`FF0000`=红，`00FF00`=绿，`0000FF`=蓝，`FFD700`=金。
