# 光标运动模糊 - 增强版 (Cursor Motion Blur Enhanced)

> 原作者：[TheatriChris](https://github.com/chrisc44890) | 原版：Cursor Motion Blur v2.0 | 二改增强：v8.2

为鼠标指针添加高速运动模糊拖尾，Direct2D 硬件加速渲染。支持延迟渲染、粒子消散、光标取色、自定义函数轨迹、发光、13 种颜色模式和点击特效。

## 功能特性

- **延迟渲染** — 拖尾头部缓动跟随光标，滞后平滑（0-10 可调）
- **粒子消散** — 拖尾释放迷你小球模拟消散，三档模式（关闭/淡出时/始终），释放间隔和加速度影响可调
- **点击星爆** — 点击时从光标位置径向迸发粒子（可开关、数量可调）
- **光标取色** — 实时提取光标下方像素颜色，拖尾自动融入背景（2 种模式）
- **函数轨迹** — 完整数学表达式解析器，支持自定义公式生成轨迹曲线，内置 4 组预设
- **波浪轨迹** — 正弦波浪曲线，轨迹呈流动波浪状
- **类锥形圆链** — 密集圆点组成的锥形拖尾，每点大小/透明度/位置存在确定性微差异
- **平滑渐变** — 拖尾从头到尾透明度渐变淡出（可开关）
- **微发光效果** — 拖尾外圈柔和发光（可开关、强度可调）
- **13 种颜色模式** — 经典黑白 / 单色 / 多色渐变 / 彩虹流动 / 暖色流动 / 冷色流动 / 霓虹脉冲 / 速度变色 / 流动条纹 / 火焰 / 极光 / 光标取色 / 光标混色
- **点击波纹** — 按下鼠标左右键时产生扩散波纹（可开关）
- **游戏检测** — 全屏 DirectX 游戏时自动禁用
- **动态渲染** — 鼠标静止且无特效时 CPU 占用为 0%

## 安装方法

1. 安装 [Windhawk](https://windhawk.net/)
2. 打开 Windhawk，点击「从代码创建 Mod」
3. 将 `cursor-motion-blur-cn.cpp` 的全部内容粘贴进去
4. 保存并启用

## 拖尾形状

| 形状 | 说明 |
|------|------|
| 锥形（经典） | 原版锥形多边形拖尾 |
| 类锥形圆链 | 密集圆点组成的锥形，密度倍率 1-5 可调 |
| 函数曲线 | 数学公式驱动的轨迹变形 |
| 波浪曲线 | 正弦波浪，幅度和频率可调 |

## 函数轨迹

自定义公式中可使用变量：
- `t` — 归一化位置（0=头部，1=尾部）
- `d` — 距头部的像素距离
- `time` — 当前时间（秒）

支持函数：`sin` `cos` `tan` `exp` `sqrt` `abs` `log`
支持运算符：`+` `-` `*` `/` `^`
常量：`pi` `e`

### 预设公式

| 预设 | 公式 | 效果 |
|------|------|------|
| 标准正弦 | `sin(d * 0.15) * 8` | 均匀正弦波 |
| 阻尼衰减 | `sin(d * 0.25) * exp(0 - t * 2.5) * 10` | 头部振幅大尾部衰减 |
| 心跳脉冲 | `abs(sin(d * 0.22)) ^ 3 * 12` | 脉冲式跳动 |
| 双频漩涡 | `sin(d * 0.1 + time * 2) * cos(d * 0.05) * 9` | 时间动态漩涡 |

## 颜色模式

| 模式 | 说明 |
|------|------|
| 经典黑白 | 原版黑白双色 |
| 单色 | 自定义颜色 + 高亮内芯 |
| 多色渐变 | 头色到尾色线性渐变 |
| 彩虹流动 | HSV 色相循环流动 |
| 暖色流动 | 红橙黄色相流动 |
| 冷色流动 | 蓝青紫色相流动 |
| 霓虹脉冲 | 自定义颜色呼吸脉冲 |
| 速度变色 | 移动越快颜色越偏红 |
| 流动条纹 | 双色交替条纹流动 |
| 火焰 | 黄到红的非线性渐变 + 闪烁 |
| 极光 | 绿紫色相动态流动 |
| 光标取色 | 实时提取光标下方像素颜色 |
| 光标混色 | 提取色与自定义色 50% 混合 |

颜色使用十六进制 RGB 格式，例如 `FF0000`=红，`00BFFF`=深天蓝。

## 粒子系统

- **模式**：关闭 / 淡出时 / 始终（静止除外）
- **密度**：每次释放 1-10 个粒子
- **释放间隔**：10-2000ms，越小越密集
- **加速度影响**：开启后鼠标速度变化越大，粒子飞散速度越快（上限 3.5x）

## 技术细节

- 架构：Windhawk Tool Mod（独立进程运行，不注入其他进程）
- 渲染：Direct2D 硬件加速，分层窗口（WS_EX_LAYERED）
- 平滑：Chaikin 曲线细分 + 子像素抗锯齿
- 表达式解析：词法分析 → Shunting-yard 转 RPN → 栈求值
- 圆链微差异：确定性 Hash01 伪随机，避免逐帧闪烁
